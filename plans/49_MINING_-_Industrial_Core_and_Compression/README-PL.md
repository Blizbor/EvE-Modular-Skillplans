# 49 MINING - Industrial Core and Compression

[🇬🇧 English](README-EN.md) | 🇵🇱 **Polski**

**Kategoria:** MINING

## Przeznaczenie

Subcapital industrial cores, kompresory pokładowe oraz zasięg kompresji flotowej.

> **Próg:** BASIC odblokowuje Medium lub Large Industrial Core I i kompresję asteroid ore; IMPROVED odblokowuje Medium Industrial Core II oraz kompresję ice i gas; STANDARD obejmuje Large Industrial Core II i wszystkie rodzaje kompresji subcapital.
