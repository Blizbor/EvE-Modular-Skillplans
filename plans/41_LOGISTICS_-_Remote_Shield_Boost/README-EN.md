# 41 LOGISTICS - Remote Shield Boost

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

**Category:** LOGISTICS

## Purpose

Remote shield booster capacitor efficiency and T2 remote shield booster access.

> **Milestone:** BASIC unlocks small T2 remote shield boosters; IMPROVED unlocks medium and large T2 modules; STANDARD is the dedicated specialist level.
