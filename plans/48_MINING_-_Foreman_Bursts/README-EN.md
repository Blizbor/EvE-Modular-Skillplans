# 48 MINING - Foreman Bursts

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

**Category:** MINING

## Purpose

Mining Foreman Burst range, duration, strength and T2 module access.

> **Milestone:** BASIC operates the T1 burst; IMPROVED unlocks the T2 burst and provides strong regular-use bonuses; STANDARD maximizes burst strength and improves reload flexibility.
