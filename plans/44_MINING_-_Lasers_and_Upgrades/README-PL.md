# 44 MINING - Lasers and Upgrades

[🇬🇧 English](README-EN.md) | 🇵🇱 **Polski**

**Kategoria:** MINING

## Przeznaczenie

Wydajność mining laserów, analiza asteroid i fitting mining upgrades.

> **Próg:** BASIC jest wejściem T1; IMPROVED odblokowuje Miner II i Mining Laser Upgrade II; STANDARD osiąga specjalistyczny próg yieldu i supportu fittingowego tego modułu.
