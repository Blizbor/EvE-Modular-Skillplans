# 21 TANK - Armor Buffer

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

**Category:** TANK

## Goal

BASIC represents a low-SP pilot who can **fit a basic armor tank and an armor rig**, not a pilot who already has all quality bonuses trained.

## Levels

### Alpha — 1.5

An Alpha pilot completes BASIC but not all of IMPROVED. The file contains every entry from the STANDARD plan that fits within Alpha limits.

Import: [`plan-1.5-ALPHA.txt`](plan-1.5-ALPHA.txt)

## Rigging rule

Across the library, a specialized rigging skill at BASIC primarily means **being able to fit the rig**, so its target is **I**. Higher levels reduce rig drawbacks and belong to later progression. `Jury Rigging III` may still appear because it is the prerequisite for specialized rigging skills.
