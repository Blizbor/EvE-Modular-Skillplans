# 01 CORE - Navigation

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

**Category:** CORE

## Purpose

A shared support module for **Navigation**. Many paths use it, but its level should follow the pilot's actual needs.

## Levels

### Alpha — 0.5

An Alpha pilot does not complete BASIC. The file contains every entry from the STANDARD plan that fits within Alpha limits.

Import: [`plan-0.5-ALPHA.txt`](plan-0.5-ALPHA.txt)

Maximum Alpha-accessible levels in this module:

- Spaceship Command IV
- Navigation IV
- Evasive Maneuvering III
- Warp Drive Operation III
- Afterburner III
- Acceleration Control III
- High Speed Maneuvering III

### 1 — BASIC

The lowest sensible entry level. It should make the competency usable without delaying the pilot with unnecessary training.

Import: [`plan-1-BASIC.txt`](plan-1-BASIC.txt)

Target levels:

- Spaceship Command IV
- Navigation IV
- Evasive Maneuvering IV
- Warp Drive Operation III
- Afterburner III
- Acceleration Control III
- High Speed Maneuvering III
- Fuel Conservation III

### 2 — IMPROVED

The intermediate practical level. This is often a good point for regular use before deciding whether the role deserves more SP.

Import: [`plan-2-IMPROVED.txt`](plan-2-IMPROVED.txt)

Target levels:

- Spaceship Command IV
- Navigation IV
- Evasive Maneuvering IV
- Warp Drive Operation IV
- Afterburner IV
- Acceleration Control IV
- High Speed Maneuvering IV
- Fuel Conservation IV

### 3 — STANDARD

The highest current library level — the **corp standard** for a pilot developing this competency. It does not mean automatically training everything to V.

Import: [`plan-3-STANDARD.txt`](plan-3-STANDARD.txt)

Target levels:

- Spaceship Command V
- Navigation IV
- Evasive Maneuvering IV
- Warp Drive Operation IV
- Afterburner IV
- Acceleration Control IV
- High Speed Maneuvering IV
- Fuel Conservation IV

## Level V rule

Level V stays in a plan when it unlocks a required module/hull/skill, is required for further progression, or is an intentional role-specific exception. After reaching `STANDARD`, further V levels are the pilot's decision rather than an automatic requirement.
