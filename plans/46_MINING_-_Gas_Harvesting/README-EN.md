# 46 MINING - Gas Harvesting

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

**Category:** MINING

## Purpose

Gas Cloud Scoop access and harvesting capacity.

> **Milestone:** BASIC supports two scoops; IMPROVED supports four and is the practical target; STANDARD enables the fifth scoop where the hull can fit it.
