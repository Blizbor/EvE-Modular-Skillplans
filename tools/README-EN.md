# Tools

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

`build-language-repo.py` creates a clean single-language shadow repository from the bilingual source repository.

```bash
python tools/build-language-repo.py PL ../EvE-Modular-Skillplans-PL
python tools/build-language-repo.py EN ../EvE-Modular-Skillplans-EN
```

The source repository remains the only editing source of truth. Shadow repositories should be treated as generated publication output.
