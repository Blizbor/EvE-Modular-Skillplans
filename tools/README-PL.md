# Narzędzia

🇵🇱 **Polski** | [🇬🇧 English](README-EN.md)

`build-language-repo.py` generuje czyste shadow repo jednego języka z dwujęzycznego repo źródłowego.

```bash
python tools/build-language-repo.py PL ../EvE-Modular-Skillplans-PL
python tools/build-language-repo.py EN ../EvE-Modular-Skillplans-EN
```

Repo źródłowe pozostaje jedynym miejscem edycji. Shadow repo powinny być traktowane jako wynik publikacji.
