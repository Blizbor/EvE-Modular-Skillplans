# Mining — Training Path

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

This path is intentionally limited. It gives a pilot several natural levels of commitment to mining without trying to document every industrial niche in EVE.

```text
MINING
├── Venture
│   ├── Pioneer — target light miner / mining side-role
│   └── Outrider
│
├── Barge / Exhumer
│   ├── Procurer → Skiff
│   ├── Retriever → Mackinaw
│   └── Covetor → Hulk
│
└── Industrial Command
    └── Porpoise → Orca
```

## Venture → Pioneer

Pioneer is not merely a transition hull. For a pilot who treats mining as a side activity, it can be the **final light-miner target**. The relevant hull module is `96 HULL - Mining Destroyer`.

## Outrider

Outrider is an intentional **side branch**: mobile command/mining support rather than a step toward Porpoise or Orca. It is not treated as a “small Orca” or a required part of the Industrial Command route.

## Barge / Exhumer

`96 HULL - Mining Barge → 96 HULL - Exhumers`

The three pairs show the natural T1 → T2 specialization routes:

- Procurer → Skiff
- Retriever → Mackinaw
- Covetor → Hulk

## Industrial Command

`96 HULL - Industrial Command Ships` leads to **Porpoise → Orca**. Orca is the higher commitment level of the same broad fleet-support/command role; Outrider remains a separate branch.

The path intentionally stops here. EVE should still leave pilots something to discover.
