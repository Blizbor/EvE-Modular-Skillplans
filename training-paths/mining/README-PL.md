# Mining — Training Path

🇵🇱 **Polski** | [🇬🇧 English](README-EN.md)

Ta ścieżka jest celowo ograniczona. Ma doprowadzić pilota do kilku naturalnych poziomów zaangażowania w mining, a nie opisywać każdą możliwą niszę przemysłową.

```text
MINING
├── Venture
│   ├── Pioneer — docelowy lekki miner / mining side-role
│   └── Outrider
│
├── Barge / Exhumer
│   ├── Procurer → Skiff
│   ├── Retriever → Mackinaw
│   └── Covetor → Hulk
│
└── Industrial Command
    └── Porpoise → Orca
```

## Venture → Pioneer

Pioneer nie jest tylko hullem przejściowym. Dla pilota, dla którego mining jest aktywnością poboczną, może być **docelowym lekkim minerem**. Odpowiednim modułem hullowym jest `96 HULL - Mining Destroyer`.

## Outrider

Outrider jest świadomym **skokiem w bok**: mobilny command/mining support, a nie szczebel prowadzący do Porpoise lub Orcy. Nie traktujemy go jako „mniejszej Orcy” ani wymaganej części Industrial Command.

## Barge / Exhumer

`96 HULL - Mining Barge → 96 HULL - Exhumers`

Trzy pary pokazują naturalne specjalizacje i przejście T1 → T2:

- Procurer → Skiff
- Retriever → Mackinaw
- Covetor → Hulk

## Industrial Command

`96 HULL - Industrial Command Ships` prowadzi do **Porpoise → Orca**. Orca jest wyższym poziomem tej samej ogólnej roli fleet support/command; Outrider pozostaje osobną odnogą.

Dalszych industrialnych nisz nie dokładamy do tej ścieżki. Jeśli pilot będzie chciał więcej — EVE nadal ma co odkrywać.
