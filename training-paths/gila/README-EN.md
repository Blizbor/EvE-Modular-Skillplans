# Gila — Training Path

[🇵🇱 Polski](README-PL.md) | 🇬🇧 **English**

The goal is a practical route to a good Gila, not checking every possible box on the way. Gila combines shield, missiles and above all medium drones, and the hull requires both racial cruiser branches.

## Foundation

`00 STANDARD → 01 IMPROVED → 02 IMPROVED → 10 STANDARD`

For PvP add `03 IMPROVED` or higher as required.

## Tank

`30 IMPROVED → 31 IMPROVED`

The active-shield plan `31` is only needed when the actual fit uses a shield booster.

## Missiles

`60 IMPROVED` plus one branch:

- `61 IMPROVED` — rockets / light / RLML path,
- `62 IMPROVED` — HAM/HML path.

There is no need to train both immediately.

## Drones — the core of the Gila

`70 IMPROVED → 71 IMPROVED → 72 IMPROVED`

T2 medium drones are a more important milestone than collecting extra side hulls. `73 Heavy & Sentry` is not required for the first sensible Gila.

## Hulls

Train `92 Caldari` + `92 Gallente` to the hull requirement and then to a practical regular-use level.

The cleanest intermediate ship is **Caracal**. Hawk can be a useful side goal for a pilot who already wants Assault Frigates; Sunesis can be a cheap utility side-step. Neither is mandatory.

## Minimal logic

**core/fitting → shield → missile support → drone support → T2 medium drones → Caldari + Gallente Cruiser → Gila**
