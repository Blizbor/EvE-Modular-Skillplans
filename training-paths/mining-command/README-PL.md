# Mining command ships

Ta ścieżka obejmuje supporty Porpoise i Orki dostępne w EvE Modular Skillplans. Katalog nie zawiera jeszcze osobnych modułów mining bursts, Industrial Core ani compression, dlatego recepty nie dopisują pojedynczych skilli z ręki. Wynik trzeba sprawdzić względem konkretnego fita.

## Alpha i Omega

**Alpha:** nie może latać Porpoise ani Orką. Plik Alpha dla `96 INDUSTRIAL COMMAND SHIPS` zawiera tylko wymagania wstępne i nie odblokowuje żadnego z tych hulli.

**Omega:** moduły CORE, shield i hull na poziomie `IMPROVED` są praktyczną bazą. Aktywny tank `31` należy dodać tylko do fita z boosterem, a support dronów `70` tylko wtedy, gdy statek kopie lub walczy dronami.

## Porpoise

1. CORE i fitting: `00`, `01`, `02`.
2. Tank: `30`; opcjonalnie `31` dla aktywnego fita.
3. Hull: `96_INDUSTRIAL_COMMAND_SHIPS`.
4. Narzędzia: `70` przy użyciu dronów; narzędzia command i compression nie mają jeszcze modułu.

TRAINING: PORPOISE_OMEGA,00_I,01_I,02_I,30_I,96_INDUSTRIAL_COMMAND_SHIPS_I

TRAINING: PORPOISE_DRONES_OMEGA,00_I,01_I,02_I,30_I,96_INDUSTRIAL_COMMAND_SHIPS_I,70_I
